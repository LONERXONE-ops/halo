# Halo

A dynamic island for the Galaxy A06 (One UI), built natively in Kotlin.

Every push to `main` builds a signed APK on GitHub Actions and publishes it under **Releases**.
If a build fails, the error is posted as an issue.

## Phase 1
- Glass island around the camera notch (idle, compact, expanded)
- Music: album art, waveform, expand for controls and progress
- Charging pop
- One UI style settings with a setup checklist and ADB commands
